# Bb 시계

iPad 가로모드 전용 풀스크린 시계. 단일 HTML 파일이며 빌드 과정이 없다.

공개 주소: https://ceek-tech.github.io/bb-clock/

## 디자인
화면을 탭하면 네 가지가 순환한다. 선택은 브라우저에 보존된다.

| # | 이름 | 구성 |
|---|---|---|
| 1 | 미니멀 산세리프 | 날짜 · 대형 볼드 시간 · 하단 날씨 |
| 2 | 에디토리얼 세리프 | 좌상단 시간 · 우하단 캡션 |
| 3 | 모노 터미널 | 상단 룰 · 초 단위 시간 · 하단 3열 데이터 |
| 4 | 스플릿 | 좌측 시간 · 우측 헤어라인 정보 컬럼 |

기본 스타일이 가로모드 기준이고 세로모드는 단순 스택으로 폴백한다.
검증 해상도: 1180×820, 1366×1024, 1112×834, 1024×768.

## 기능
- 날씨: Open-Meteo (기본 서울, 설정에서 도시 변경, 30분마다 갱신)
- 사용자 폰트: ttf/otf/woff/woff2 업로드 시 시간 표시에 적용되고 IndexedDB에 보존된다.
  적용 중에는 네 디자인 모두 굵기가 700으로 통일된다.
- 4초간 조작이 없으면 하단 컨트롤이 사라진다

## iPad에서 쓰기
Safari로 위 주소를 열고 공유 > 홈 화면에 추가. 전체화면으로 실행되며
Safari UI가 보이지 않는다.

화면을 계속 켜두려면 설정 > 디스플레이 및 밝기 > 자동 잠금을 안 함으로 둔다.
Screen Wake Lock API는 iOS Safari에서 지원되지 않아 페이지가 스스로 막지 못한다.

## 배포
main 브랜치 루트를 GitHub Pages로 서빙한다. index.html을 수정하고 푸시하면 반영된다.
